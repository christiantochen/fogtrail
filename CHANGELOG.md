## v0.2.2 (2026-11-07)

First public release. Everything Fogtrail does today:

### Features

- Read-only data browser for Redis, with Valkey, Dragonfly and KeyDB through the same driver
- Key tree with a configurable delimiter, server-side search and arrow-key navigation
- Viewers for string, hash, list, set, sorted set and stream (paging and consumer groups), with JSON colors
- Server info panel and a database switcher
- Connection profiles with passwords in the system keychain, TLS and ACL users, and one-step switching between connections
- Paste a redis:// or rediss:// URL into Host to fill the connection form, and Copy as URL (the password is left out unless you include it)
- Quick open (Cmd/Ctrl+K) to jump to a key or switch connection
- Pinned keys per connection, in the sidebar and in Quick open
- Live TTL countdown in the key header
- Find in value, with highlights, stepping through matches and filtering table rows
- Fold and unfold JSON blocks, with Collapse all
- Auto-refresh the open key on a timer, flashing what changed
- Copy menu with a confirmation notice, and Shift+Cmd+C
- Resume where you left off at launch
- Native menus, keyboard shortcuts, window state restore and a strict content security policy
- Light and dark themes
- In-app updates: Check for Updates in the menu and a silent check on launch, with signed releases
- About dialog on Windows (macOS uses its own)

### Maintenance

- Installers for macOS (Apple Silicon and Intel) and Windows, built by CI from tags, with a Download table in each release
- Releases are cut from feat: and fix: commits, with a manual option to force one
- CI with lint, unit tests and WebKit screenshot checks
- SECURITY.md, issue forms, a pull request template and weekly Dependabot updates
